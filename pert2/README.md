# Praktikum Pemrograman Mobile - Modul 2

Modul 2 berisi latihan membuat tampilan aplikasi yang lebih terstruktur dan mulai menggunakan data. Pada modul ini juga dipelajari cara berpindah halaman dan mengirim data dari satu halaman ke halaman lainnya.

## Materi yang dipelajari

### 1. Layout dengan Container, Padding, Row, dan Column

Widget layout digunakan untuk mengatur posisi dan jarak antar elemen pada aplikasi.

* `Container` digunakan untuk membuat wadah dan mengatur ukuran atau tampilan.
* `Padding` digunakan untuk memberikan jarak di dalam suatu widget.
* `Row` digunakan untuk menyusun widget secara horizontal.
* `Column` digunakan untuk menyusun widget secara vertikal.
* `Expanded` digunakan agar widget dapat menyesuaikan ruang yang tersedia.

### 2. Membuat Model Data

Mempelajari cara membuat `class` sebagai model untuk menyimpan data agar lebih terstruktur.

Contohnya, data makanan memiliki nama, harga, dan kategori yang disimpan dalam satu object.

### 3. ListView.builder

`ListView.builder` digunakan untuk menampilkan banyak data dalam bentuk daftar.

Widget ini cocok digunakan ketika data yang ditampilkan berasal dari sebuah list.

### 4. Card dan ListTile

`Card` digunakan untuk membuat tampilan data menjadi seperti kartu, sedangkan `ListTile` membantu membuat tampilan daftar yang lebih rapi.

### 5. Format Harga Rupiah

Mempelajari cara mengubah angka menjadi format harga Rupiah agar lebih mudah dibaca.

Contohnya:

`150000` menjadi `Rp150.000`.

### 6. Navigation

Mempelajari cara berpindah dari satu halaman ke halaman lainnya menggunakan `Navigator.push()`.

Pada modul ini data dari halaman utama juga dikirim ke halaman detail untuk menampilkan informasi yang lebih lengkap.

### 7. Navigator.pop()

`Navigator.pop()` digunakan untuk kembali ke halaman sebelumnya setelah pengguna selesai melihat halaman detail.
