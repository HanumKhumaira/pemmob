# Modul 1 — Dasar Flutter

Modul 1 berisi pembelajaran dasar Flutter, mulai dari mengenal struktur aplikasi sampai menggunakan widget dasar untuk membuat tampilan.

## Materi yang dipelajari

### 1. Membuat Project Flutter

Mempelajari cara membuat project Flutter dan mengenal struktur folder serta file yang digunakan dalam aplikasi.

### 2. StatelessWidget

`StatelessWidget` digunakan untuk membuat tampilan yang tidak memiliki perubahan data selama aplikasi berjalan.

### 3. StatefulWidget

`StatefulWidget` digunakan ketika tampilan membutuhkan perubahan data atau kondisi selama aplikasi berjalan.

### 4. setState()

`setState()` digunakan untuk memberi tahu Flutter bahwa terdapat perubahan data sehingga tampilan dapat diperbarui.

### 5. Scaffold dan AppBar

`Scaffold` digunakan sebagai struktur dasar halaman Flutter, sedangkan `AppBar` digunakan untuk membuat bagian atas halaman.

### 6. Widget Dasar

Mempelajari penggunaan beberapa widget dasar seperti:

- `Text`
- `Icon`
- `Column`
- `Row`
- `Container`
- `ElevatedButton`

Pada Modul 1 saya membuat aplikasi Flutter sederhana dan mencoba beberapa widget dasar serta memahami konsep StatelessWidget, StatefulWidget, dan perubahan state menggunakan `setState()`.
